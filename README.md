# Aryaman Modi portfolio

A responsive static portfolio built from the supplied `index.html` content and inspired by the attached video’s dark editorial look, atmospheric lighting, oversized type, and glass lens interaction. The profile section uses the original photo and its earlier light editorial strip design.

## Files

- `index.html` — portfolio content and page structure
- `styles.css` — responsive layout, gradients, 3D orb, and motion styles
- `script.js` — cursor lens, mobile menu, and scroll reveals
- `assets/` — the original and redesigned profile images, project images, and certificate images

Certificate thumbnails open in a larger preview. The gallery includes the AWS Cloud Practitioner and LinkedIn Learning React Essential Training certificates.

Open `index.html` in a browser to view the site. Google Fonts load from the internet; system sans-serif fallbacks are included.
